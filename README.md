# 🌿 D2C Skincare Analytics Dashboard

## 📌 Project Overview

This project is an interactive Business Intelligence dashboard built using **Power BI** to analyze the performance of a Direct-to-Consumer (D2C) skincare brand.

The dashboard provides insights into sales performance, customer behavior, product trends, returns, and regional performance to support data-driven business decisions.

---

## 🎯 Objectives

* Analyze sales and revenue performance
* Track customer acquisition and retention
* Identify top-performing products
* Monitor return orders and return rates
* Compare regional performance
* Generate actionable business insights

---

## 📊 Dashboard Features

### Executive KPIs

* Total Revenue
* Total Orders
* Total Returns
* Total Customers

### Sales Analysis

* Monthly Revenue Trend
* Orders Trend
* Revenue by Category
* Revenue by Product

### Customer Analysis

* Customer Demographics
* Regional Customer Distribution

### Product Analysis

* Best Selling Products
* Product Category Performance
* Product Return Analysis

### Geographic Analysis

* State-wise Sales Performance
* State-wise Order Distribution
* Regional Return Analysis
